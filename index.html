Supabase 연결 설정

검사 결과를 Supabase 데이터베이스에 저장하고 언제든 다시 불러오려면 프로젝트 정보를 입력하세요. Project Settings → API 메뉴에서 Project URL과 anon public key를 확인할 수 있습니다.

anon key는 원래 클라이언트 코드에 공개적으로 포함되는 값으로, 그 자체로는 비밀 정보가 아닙니다. 실제 결과 데이터의 비공개 여부는 Supabase의 Row Level Security 정책과 로그인 여부로 결정됩니다. 로그인하지 않으면 결과를 저장하거나 조회할 수 없습니다.
